# Axmadullo Abdurashidov — Portfolio

Axmadullo Abdurashidov’ning shaxsiy portfolio sayti. React, TypeScript va Vite yordamida qurilgan.

## Ishga tushirish

```sh
npm install
npm run dev
```

## Tekshirish va build

```sh
npm run build
npm run preview
```

## Asosiy texnologiyalar

- React 19 va TypeScript
- Vite
- Framer Motion
- Lucide React
